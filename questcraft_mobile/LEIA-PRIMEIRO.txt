QUESTCRAFT MOBILE — EXPERIMENTAL

Este APK é uma adaptação do QuestCraft oficial 6.0.0, não foi testado em
um celular e pode não abrir. Ele NÃO inclui o runtime, o rastreamento de mãos
ou o Minecraft: Java Edition. Leia as instruções completas e limitações em:
https://github.com/stumbledayoh-max/apk/blob/main/questcraft_mobile/README.md
(Em uma branch ainda não mesclada, abra o README da própria branch.)

1. Em um telefone Android 10+ ARM64 com câmera e sensores, instale o PhoneXR
   FULL 2.0.1 do projeto original (NÃO a versão BE, que não tem câmera):
   https://github.com/samrat1games/phonexr/releases/tag/v2.0.1
2. Abra o PhoneXR, permita a câmera e instale/ative o PhoneXR Runtime quando
   ele solicitar. Na biblioteca do PhoneXR, abra o QuestCraft por lá: o app
   é quem inicia o serviço de mãos e entrega sensores ao runtime OpenXR.
3. Instale QuestCraft-Mobile-debug.apk, volte ao PhoneXR e execute-o por lá.
   Se não conseguir instalar, verifique CPU/Android e se já há outra versão
   do pacote com assinatura diferente. DESINSTALAR A VERSÃO ANTIGA PODE APAGAR
   SEUS DADOS: faça backup antes.
4. O jogo pode precisar baixar componentes adicionais e exige conta Microsoft
   com Minecraft: Java Edition. Controle Bluetooth pode ser necessário.

A assinatura é de TESTE, gerada para este build, diferente da assinatura do
QuestCraft. Cada execução do GitHub Actions usa uma chave nova: para atualizar,
pode ser necessário desinstalar a build anterior (após fazer backup).
Não compartilhe dados pessoais ou senhas com o autor do patch.
