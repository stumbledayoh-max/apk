QUESTCRAFT MOBILE — APK ÚNICO EXPERIMENTAL

Este APK é uma adaptação não oficial do QuestCraft 6.0.0. O runtime OpenXR,
a ponte de câmera/mãos e o modelo estão DENTRO do APK. Você não precisa
instalar o aplicativo PhoneXR nem um runtime separado.

ATENÇÃO: não foi validado em celular físico. Pode não abrir, travar, mostrar
aviso de hardware ou não reconhecer movimentos. Mãos, giroscópio e gameplay
não foram comprovados. A captura antiga no repositório é apenas um aviso de
hardware, não uma imagem do jogo funcionando.

1. Use um Android 10+ ARM64 com câmera e sensores. É necessária internet para
   os componentes que o QuestCraft original baixa no primeiro uso.
2. Instale QuestCraft-Mobile-debug.apk e abra pelo ícone do jogo. Para tentar
   rastreamento de mãos, permita a câmera quando solicitado. A câmera traseira
   é usada pela ponte experimental; iluminação e posição influenciam o resultado.
3. O jogo pode baixar componentes adicionais. O QuestCraft original informa
   que o jogo completo exige uma conta Microsoft com Minecraft: Java Edition;
   o lançamento original também menciona um modo de demonstração. A compatibilidade
   de ambos nesta adaptação não foi verificada. Um controle pode ser necessário.

A assinatura é de TESTE e difere da assinatura original. Cada build do GitHub
Actions gera uma chave nova; o Android pode exigir a desinstalação da versão
antiga antes de instalar outra. DESINSTALAR PODE APAGAR SEUS DADOS: faça backup
antes. Não compartilhe senhas com o autor deste patch.

Consulte README-DETALHADO.md para instruções de compilação e limitações.
